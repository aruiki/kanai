動作環境

項目条件
OSWindows 10 1809以降 / Windows 11・64bit
メモリ8 GB以上、16 GB推奨
GPU AIVulkan対応の専用GPU、VRAM 3 GiB以上。NVIDIA / AMD / Intel Arc
GPUがないPCCPU向けLow設定。GPU Standardと品質・速度が異なります
ディスク約1.7 GBの空き容量

内蔵GPUはAIに使いません。ARM版Windows向けの配布はありません。PythonやCUDAの手動セットアップは不要です。

インストールは、1画面。

  1. 公式ReleaseのMSIをダウンロードして開きます。
  2. 「インストール」（導入済みなら「更新」）を押し、Windowsの確認を許可します。完了の画面が出たら終わりです。
  3. Windows + Space → Asteria日本語入力を選びます。

「開いているアプリを閉じてください」と求めることはありません。設定はスタートメニューの「Asteria」から開けます。

SmartScreenが表示されたとき

配布MSIは未署名です。「WindowsによってPCが保護されました」というSmartScreen画面が表示される場合があります。SmartScreenはファイルや発行元の評判も確認します。この画面だけでマルウェアが検出されたとは判断できませんが、安全性の保証でもありません。

この公式GitHub Releaseから取得したAsteria64.msiであることを確認し、続行する場合は 詳細情報 → 表示内容を確認 → 実行を選びます。「実行」がない管理対象PCや、別の脅威名を伴う検出には、この手順を適用しないでください。SmartScreenやDefenderを無効にする操作は不要です。

更新とアンインストール

新しいMSIを開いて「更新」を押すだけで、設定・学習・ユーザー辞書を引き継ぎます。v3.0.0以降どうしの更新は再起動もいりません。v2.0.0以前からの更新では導入先が変わるため、最後にWindowsの再起動をお願いします（再起動まで、更新前から開いていたアプリでは日本語に変換できません）。

削除はWindowsの「設定 → アプリ」からAsteria日本語入力を選びます。設定・学習・ユーザー辞書のデータは残り、入れ直すと元どおりに使えます。
