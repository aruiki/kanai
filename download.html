DOWNLOAD & INSTALL

導入は4手順。
ただし、読むべき制限があります。

公開版は v0.1.0-beta.2（未署名・未完成のプレリリース）です。モデル同梱でダウンロードは約1.1 GB、AI有効時のメモリは検証環境で子プロセス約1.6 GBでした。

導入の前に

未署名です。Windows SmartScreen / publisher の警告が出ます。警告を避けるために SmartScreen、Smart App Control、ウイルス対策、企業ポリシーを無効化しないでください。日常利用の安定性は保証されません。この版のAIは起動しますが、変換結果を変えません（実測）。体感される変換品質はMozc baselineのものです。

名前の注意

パッケージ内部の ProductVersion とファイル名は 0.1.0 です（tag / release 名は v0.1.0-beta.2）。同一物かどうかは必ずSHA-256で照合してください。Setup.exe は埋め込みMSIを一時フォルダへ展開してWindows Installerを起動するlauncherで、MSI単体でも導入できます。両者は同一候補です。

REQUIREMENTS

動作環境

  • Windows 11 x64 — 検証は 1台・1ユーザー・Windows 11 build 26200 のみです。
  • ARM64 は未検証。Windows 10 も未検証です。
  • 空き容量 — ダウンロード約1.1 GB（モデル同梱）。
  • メモリ — AI有効時、子プロセス（llama-server）で約1.6 GB。
  • CPU実行のみ。同梱AIはGPUを使用しません。
  • 管理者権限（UAC） — per-machine の導入に必要です。

INSTALL

導入手順

Setup.exeを起動した後にビルド・手動コピー・コマンド入力は不要です。必要なのはUACの承認だけです。

  1. リリースページから KanaAI-0.1.0-Setup.exe をダウンロードし、SHA-256と照合します。
  2. Setup.exe を起動し、WindowsのUACを承認します。
  3. Win+Space で KanaAI を選びます。導入直後は自動で既定になりません（理由）。
  4. 半角/全角キーでIMEをONにして入力します。

MSI単体でも導入できます

Setup.exe は埋め込みMSIを一時フォルダへ展開してWindows Installerを起動するlauncherです。KanaAI-0.1.0-x64.msi を直接実行しても同じ候補が導入されます。

FIRST RUN

導入直後の挙動（Windowsの慣例とは違います）

この版には 0007-kanai-ime-open-by-default というパッチが入っており、導入直後のIMEは既定でONになります。Windowsの慣例とは異なります。

これは欠陥修正ではなく挙動変更です。開発の初期段階では「導入直後に日本語が入力できない欠陥の修正」と位置づけていましたが、それは誤りでした。IMEのON/OFFと、かな／半角英数の入力モードは別の状態です。新しいアプリでIMEがOFFから始まり、そのまま打つと英字が出るのはMicrosoft IMEでもATOKでも通常の挙動で、欠陥ではありません。この訂正を記録として残します。

実装上は、Mozcの TipStatus::IsOpen が open/close compartment の存在しないとき false を返し、新規プロファイルはそれを持たないための対応です。保存済みの値は必ず勝つので、自分でIMEを閉じたユーザーが毎回開かされることはありません。影響は実質的に初回だけです。パッチは64bit・32bit両方のTIPに入っています。

もう1つの既知の制限

導入ユーザーへの入力方式の有効化レコードが書けていません。MSIには該当のHKCUコンポーネントが含まれていますが、per-machine インストールでは導入ユーザーのhiveに着地しないことを実測しました（Setup.exe経由・MSI直接のいずれでも userActivationEnable が空）。入力自体はTSF登録経由で動作しますが、導入直後に Win+Space でKanaAIを選ぶ操作が必要です。

AI SWITCH

AIを止める／戻す

同梱AIは既定でONです。止めたいときはコマンドプロンプトから実行します。

"C:\Program Files\KanaAI\kanai-broker.exe" --disable-local-ai
"C:\Program Files\KanaAI\kanai-broker.exe" --enable-local-ai
"C:\Program Files\KanaAI\kanai-broker.exe" --ai-status

自分のユーザー設定だけを書き換えます。反映は次に入力方式が起動したときです。

実測では、--disable-local-ai を実行したブローカーは 0.42秒で「起動しない」と報告し、runtime子プロセスを作りません。AIが未起動・タイムアウト・異常応答・停止のいずれでも、変換はMozc baselineがそのまま使えます。AIはキー入力の同期処理には入りません。

ネットワークアクセスは一切ありません。runtimeはloopback（127.0.0.1）のみでlistenし、プロセスごとの鍵で保護されます。起動時に同梱バイトのハッシュ検証を行います（実測0.650秒、2ファイル・1,117,324,349バイト・runtime 51エントリ）。

UNINSTALL

削除

Windowsの設定 → アプリ → インストール済みアプリから「KanaAI Development Preview」をアンインストールします。

クリーンな削除は機械検証済みです。インストーラのライフサイクル11フェーズ（クリーン導入／TSF登録／クリーンアンインストール／MSI直接導入／同一ProductCodeへの再インストール／上位版での上書き／下位版の拒否／最終アンインストール／独立した不在確認／cleanupの冪等性）がすべてpassしたreceiptがあり、cleanup後に C:\Program Files\KanaAI が不在で孤立要素がないことを確認しています。詳細は検証状況にまとめてあります。

TROUBLESHOOTING

動かないとき

AIが起動しない場合は、次のいずれかのログの内容を添えてGitHub Issuesへ報告してください。

%LOCALAPPDATA%\KanaAI\broker-startup.log
%USERPROFILE%\AppData\LocalLow\KanaAI\broker-startup.log

このログは設定値・パス・入力テキスト・トークンを含みません。報告時は個人情報・辞書・APIキーを伏せてください。あわせてWindowsのバージョン、KanaAIのリリース番号、発生したアプリ名を添えると調査できます。

日本語入力が始まらない場合は、まず Win+Space でKanaAIが選ばれているか、半角/全角でIMEがONになっているかを確認してください。導入直後は自動で既定になりません。
