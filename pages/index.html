03 / ARCHITECTURE

Rustが全体を調整。
shellはただの入口。

一つのsession contractを、OSごと・言語ごとに再利用します。Browser labは実験室であり、本番IMEの依存関係ではありません。

L1 / NATIVE

イベントを運ぶだけ

Fcitx5・TSF・InputMethodKitは、キーと候補・commitを翻訳。順位・学習・HTTPを持ちません。

L2 / RUST

状態の唯一の持ち主

generation、deadline、privacy、ranking、learning。AI resultが古ければdropします。

L3+ / OPTIONAL

境界の向こう側

Mozc adapterはprotocolを隔離。network layerはkey pathの外。local resultが常にfallbackです。

05 / PRIVACY

04

消したものは、消す。

entry、aggregate、history、profileを区別して削除します。target architectureであり、現在のpreviewにおける完成機能ではありません。

NOT A TSF / IME

全アプリで使える
IMEではありません。

このbetaは 127.0.0.1 でWorkbenchとCLIを起動します。Windowsのkeyboard listにも他アプリにも入りません。

  • Windows設定にTSF TIP / DLLを登録しない

08 / HONEST LIMITATIONS

できることに、
見える線を引く。

early-stage projectのpreviewとして、期待と現実を同じ場所に置きます。

01

ネイティブIMEは roadmap only

フェーズ1のWindows版は、local WorkbenchとCLIのsource-build previewです。OSへのIME登録、system-wide candidate window、secure field behaviorを存在するものとして扱うことはできません。

02

Mozcはbuild prerequisite

pinned submoduleからC++ bridgeをbuildします。floatingなMozcやBazel versionを同じものとみなさず、現時点でstableなupstream releaseはありません。

03

AI modelは別物

モデルの重みは同梱・ダウンロードしません。model sizeは目安で、品質、速度、互換性を保証しません。誤変換は起こり得ます。

05

benchmarksは未公開

記載したlatencyやmemoryはengineering budgetです。platform、CPU、power mode、dictionaryを含む実測値をreleaseで公開するまでclaimではありません。

06

第三者termsは別

Mozc code、dictionary data、model、font、domain packはそれぞれのlicenseとnoticeを維持します。KanaAIのlicenseがそれらを再licenseすることはありません。

09 / FAQ

気になることを、
そのまま。

product promiseとpreviewのgapを明示することが、KanaAIのprivacy設計の中心です。

product contractを読む ↗
今、Mozcだけで使えますか？+

はい。KanaAIのtargetは、Mozc conversionを土台にしたlocal-first runtimeです。modelやnetworkがなくても、compositionとconversionは成立する設計です。現在のsnapshotで利用できる範囲はsource workbenchであり、installable IMEではありません。

ダウンロードしてインストールできますか？+

Windows Workbench/CLI betaは、PowerShellでソースからbuildする開発者向けpreviewです。公式binary、installer、published portable ZIP、Scoop packageはまだありません。存在しないダウンロードをボタンで示すのではなく、build guideとsourceだけを案内します。release artifactができるまでは、source metadataの 0.1.0 を公開版とみなさないでください。

入力した文章はデフォルトで送られますか？+

target designでは、composition、conversion、local learningはaccountやnetworkなしで動きます。任意のwriting assistやcloud featureは別々に明示して有効化します。remote endpointsは初期状態では無効です。ただしdev APIとbrowser workbenchはproduction privacy implementationではありません。

AIは変換を奪いますか？+

奪いません。Mozc resultを先に返し、AIはbounded reranking、ambiguity、explicit repairというsecond stageです。mode、preedit、commit、undo、learning persistenceはRust/session FSMがauthoritativeです。timeoutや不正なresponseはbase resultへfallbackします。

対応OSは決まっていますか？+

proposed orderはLinux/Fcitx5 first、Windows/TSF second、macOS/InputMethodKit thirdです。public betaやstableな日付を約束するものではありません。各platformでaccessibility、secure input、focus recovery、signingのgateを通してから公開します。

ライセンスと第三者componentは？+

KanaAI-owned sourceはMITまたはApache-2.0の選択です。Mozc本体、Google-authored code、dictionary data、モデルの重みなどはそれぞれのtermsを保持します。sourceやbinaryを配布する前に、third-party notices、licenses、SBOMを確認してください。
