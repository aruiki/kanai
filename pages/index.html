インストールは、1画面。

  1. ダウンロードして開くAsteria64.msi（約1.7 GB）
  2. 「インストール」を押すWindowsの確認を許可すると、完了の画面が出ます。
  3. Windows + Space で選ぶ「Asteria日本語入力」を選べば使えます。

「開いているアプリを閉じてください」と求めることはありません。v3.0.0以降の更新は再起動もいりません（v2.0.0以前からの更新だけ、最後に再起動をお願いします）。アンインストールしても学習した内容は残り、入れ直せば元どおりに使えます。

よくある質問

GPUがないPCでも使えますか？

使えます。CPU向けの設定（Low）で動きます。精度と速さは、GPU（Vulkan対応の専用GPU、VRAM 3 GiB以上）のStandardと同じではありません。

「WindowsによってPCが保護されました」と出ました。

配布ファイルは未署名のため、SmartScreenが表示されることがあります。公式のReleaseから入手したことと、添付のSHA-256を確かめてから「詳細情報 → 実行」を選んでください。導入方法

容量が大きいのはなぜですか？

変換に使うAIのモデルと実行環境を同梱しているためです。PythonやCUDAを別に入れる必要はありません。

Google日本語入力やMicrosoft IMEと一緒に入れられますか？

入れられます。Windows + Space でいつでも切り替えられます。

どんなときに間違えますか？

文の意味で決まる同音語（駐車／注射など）や、人名・店名などの固有名詞は、ほかより誤りが多くなります。打ち終えてすぐSpaceを押すと、候補まで0.3秒ほどかかることがあります。既知の問題

動作環境は？

Windows 10 1809以降 / Windows 11（64bit）、メモリ8 GB以上（16 GB推奨）、ディスク約1.7 GB。GPUのAIはVulkan対応の専用GPU（NVIDIA / AMD / Intel Arc、VRAM 3 GiB以上）を使います。内蔵GPUは使いません。
