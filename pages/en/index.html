ABOUT KANAAI

What KanaAI is

Mozc does the conversion

Dictionary, morphological analysis, candidate generation, history and OS integration come from Mozc. KanaAI does not reimplement them without a measured or maintenance reason.

The AI runs on your PC

Qwen2.5-1.5B-Instruct and a llama.cpp runtime are bundled and run on the CPU. No cloud AI account, no API key, no network access, no telemetry.

The work is public

KanaAI's own source is MIT OR Apache-2.0. Implementation, measured receipts and open problems are recorded in the repository.

What works today, and what does not

Mozc-based Japanese input and startup of the bundled AI are confirmed on one machine. The AI does not yet improve conversion accuracy, and daily-use stability is not guaranteed. Independent verification of the finished product is not complete.

INSTALL

Installing the beta

The download is about 1.1 GB because the model and runtime are bundled. After Setup.exe starts there is no build step, no manual copy and no command to type — only the Windows UAC prompt.

  1. Download KanaAI-0.1.0-Setup.exe from the release page and compare its SHA-256 (F61D86BF95AC97723D733A76B33BE6BB8FF6FFED6E9A3973BDC1FADB641A17A0).
  2. Run Setup.exe and approve the UAC prompt.
  3. Press Win+Space and choose KanaAI. It does not become the default automatically in this build.
  4. Turn the IME on with the 半角/全角 key and type.

Read this before installing

The build is unsigned. Do not disable SmartScreen, Smart App Control, antivirus or corporate policy to get past the warning. Daily-use stability is not guaranteed, and this build is not a completed product.

To turn the AI off, run "C:\Program Files\KanaAI\kanai-broker.exe" --disable-local-ai. It writes only your own user setting and takes effect the next time the text service starts. Conversion keeps working through Mozc whether the AI is off, slow, unavailable or crashed.

To remove KanaAI, use Settings → Apps → Installed apps and uninstall KanaAI Development Preview.

PRIVACY

Where your text goes

Nowhere outside your PC. There is no network access at all. The runtime listens on loopback 127.0.0.1 only and is protected by a per-process key. There is no telemetry, no account and no API key.

In protected fields such as password boxes, context collection, the AI and learning are stopped. The IME never treats an untrusted interpretation of the context reported by the OS as a security boundary. Learning never happens from uncommitted input, and stale results or rewritten candidate ids are rejected.

Mozc history and learning data live in the Mozc profile and can be deleted from Mozc's own settings. KanaAI caches stay on your PC.
