FAQ

Does it work without a GPU?

Yes, with the CPU-oriented Low setting. Quality and speed differ from Standard on a dedicated Vulkan GPU with at least 3 GiB VRAM.

Windows says “Windows protected your PC”.

The installer is unsigned, so SmartScreen may appear. Confirm it came from the official GitHub Release and check the attached SHA-256, then choose “More info → Run anyway”.

Why is it so large?

The AI models and runtime are bundled, so there is nothing else to install — no Python or CUDA setup.

Can I keep Google Japanese Input or Microsoft IME?

Yes. Switch any time with Windows + Space.

System requirements?

Windows 10 1809 or later / Windows 11 (x64), 8 GB RAM (16 GB recommended), about 1.7 GB disk. GPU AI uses a dedicated Vulkan GPU (NVIDIA / AMD / Intel Arc) with 3 GiB+ VRAM; integrated GPUs are not used.
