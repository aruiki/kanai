KOTORI JAPANESE INPUT

IMEの比較と開発状況

Microsoft IME・Google日本語入力と同条件で比較。AJIMEE 198問でKotori 88.4%、Microsoft 59.6%、Google 58.1%。実際の問題文、測定条件、CSVとv1.0.0の公開状況を掲載。

AJIMEE-Benchでは、どんな文を変換する？

単語を知っているだけでなく、文の意味に合う漢字を選ぶ必要があります。実際の評価データから3問を抜粋しました。

全IMEで、前の文を渡さず、Spaceを1回押した第1候補をEnterで確定して採点。数字・記号はNFKCで揃え、AJIMEE 200問のうち入力できない2問を除いた198問を比較しています。学習は既定設定のまま、問ごとにテキストとフォーカスをリセットしています。

この測定はbeta.8の記録です。現在のv1.0.0 / v1.1を再測定した数値ではありません。同音語・人名・打ち間違いはプロジェクト独自の各40問です。打ち間違い補正ではMicrosoft IMEと同率、Google日本語入力を下回りました。

確認が続いていること

  • コード署名はv1.0.0 / v1.1.0-rc.1では未実施です。
  • 長時間試験、ノートPC・設定画面・更新導入などの受け入れ確認に残項目があります。
  • v1.1の「手を止めたときの候補表示」は、メモ帳・ブラウザー・Wordなどの実機TSF確認が必要と記録されています。
  • CPUで長い文を打ってすぐSpaceを押すと、AIが間に合わずMozcの結果になる場合があります。
  • 評価用セットの数値を、すべてのアプリ・PC・文章へ一般化することはできません。
