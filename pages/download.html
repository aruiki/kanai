使い方と困ったとき

必要な環境

項目必要な環境おすすめ
OSWindows 10 1809以降 / Windows 11（x64）Windows 11

GPUなしでも動作。内蔵GPUはAIに使いません。専用GPU・Vulkan対応・VRAM 3 GB以上

AIモデルとGPU実行環境は同梱しています。GPUのドライバー以外にCUDAなどの準備は不要です。ARM版Windowsには対応していません。動作確認済みのGPUとしてRTX 3060が記録されています。

MSIを実行して、入力方式を切り替える。

  1. GitHub Releasesでリリースノートを確認し、Kotori64.msiをダウンロードします。
  2. MSIをダブルクリックし、管理者の確認（UAC）を承認します。
  3. Win + SpaceでKotori日本語入力へ切り替えます。半角/全角で日本語入力をON/OFFできます。
  4. デスクトップまたはスタートメニューの「Kotori日本語入力の設定」を開き、「AI変換」タブで品質とAIの状態を確認できます。

v1.0.0 / v1.1.0-rc.1は未署名のため、Windowsの警告が表示される場合があります。ファイルの照合方法と対処は利用ガイドへ。

更新・アンインストール

v0.3.0-beta.6以降は、新しいMSIを上書きして更新できます。設定・学習・ユーザー辞書は引き継ぎます。それより古い版は一度アンインストールしてから導入してください。入力中のアプリがあると、再起動を求められる場合があります。

削除はWindowsの「設定 → アプリ」からKotori日本語入力を選びます。ユーザーデータは再導入時に引き継ぐため残ります。削除後のデータの扱いはプライバシーと削除で説明しています。

自動更新の通知はありません。Releasesで更新を確認できます。
