Kotori Japanese Input

Kotori is a free, open-source Japanese input program for Windows. It uses Mozc with local AI conversion and prediction. Feedback and contributions are welcome.

Download for Windows日本語

Stable v1.0.0 · Windows 10 / 11 x64 · CPU and dedicated GPU

MODELS INCLUDEDAI processing runs locally

One MSI includes the models and runtime. No cloud account or additional CUDA installation is required.

Features

Local conversion

Mozc and zenz generate candidates. zenz and TinySwallow-1.5B score them in context. Dictionary checks reject candidates that do not match the reading.

AI prediction

The model computes continuations in the background. Select a candidate labelled AI using Tab.

CPU fallback

A dedicated Vulkan GPU with at least 3 GB VRAM enables Standard and higher modes. PCs without one use the CPU-oriented Low configuration.

Published evaluation results.

Standard scored 91.5% on the 200-item AJIMEE-Bench and 96.3% on a 300-item held-out set, compared with 51.0% and 82.3% for Mozc alone. These project-reported measurements use preceding context and an RTX 3060; they do not guarantee accuracy on every sentence or PC.

Stable release and release candidate.

The latest stable release at the content review date is v1.0.0. v1.1.0-rc.1 is a prerelease that refreshes AI conversion and prediction candidates after typing pauses. Both are unsigned. Code signing, long-duration and real-device acceptance checks still have remaining work.

Requirements: Windows 10 1809 or later / Windows 11 x64, 8 GB RAM and 1.7 GB free disk space. ARM Windows is unsupported.
