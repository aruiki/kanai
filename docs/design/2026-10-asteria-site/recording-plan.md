# 実入力の録画 — 難文3例

状態: 未収録。READMEとサイトへの実録画の埋め込みは未実施。偽のGIF・空の再生枠は公開しない。

## 収録する内容

Windowsのメモ帳を新規に開き、文字サイズを24〜28px、表示範囲をおよそ1000×500にする。個人文書・通知・ユーザー名を録画範囲に含めない。Snipping Toolの画面録画等で入力欄と候補が見える範囲だけを指定する。

Asteriaへ切り替え、読みをローマ字のキーで実際に入力する。完成文の貼り付けや、変換後の正解文への置き換えはしない。各文のSpace変換・候補・Enter確定を見せる。複数候補を選んだ場合はその操作もそのまま残す。

1. きしゃのきしゃがきしゃできしゃした。 → 目標例: 貴社の記者が汽車で帰社した。
2. おんせいにんしきのせいどがあがり、せいどのみなおしがすすんだ。 → 目標例: 音声認識の精度が上がり、制度の見直しが進んだ。
3. きしょうちょうは、きしょうのへんかをかんそくした。 → 目標例: 気象庁は、気象の変化を観測した。

いずれもデモの目標文で、Asteriaがこの通り出したという記録ではない。難しい同音語や固有名詞の選択を見せる。正解率の測定や公平なIME比較には使わない。

## 版と結果を固定する

2026-10-15の調査では、このPCの導入済みMSIは3.34.6337.100、公開最新版はv1.1.3 / 3.34.6431.100だった。既存の導入版を最新版と表示しない。普段のIMEを無断更新することは避ける。最新版の収録なら検証用Windows環境へ当該MSIを導入し、同一版を録画する。

収録時にメモする項目: 日付、MSI/バイナリの版とSHA-256、アプリ、GPU/CPU、品質モード、初回ロードか暖機後か、前の文、各読み・操作・実出力。失敗や候補選択も保存する。速度を変更する場合は倍率を明記し、元動画を保持する。
