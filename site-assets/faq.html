AsteriaのFAQ

Asteriaとは何ですか？

Mozcの辞書・文節処理・学習を基盤に、GPUで動くローカルAIが候補を生成・採点するWindows向け日本語入力です。続きの予測はTabで選べます。

GPUがなくても使えますか？

CPU向けのLow設定で動作します。GPUのStandardと同じ品質・速度ではありません。GPU AIにはVulkan対応の専用GPU・VRAM 3 GiB以上を使用し、内蔵GPUは使いません。

通信やクラウドのアカウントは必要ですか？

モデル・辞書・実行環境はMSI同梱。導入後の変換とAI処理はPC内で動き、入力文章を外部サーバーへ送信しません。変換のためのアカウントや外部APIは不要です。

どの版をダウンロードすればよいですか？

このサイトはv1.1.4-rc.4をリリース候補として紹介しています。未署名のAsteria64.msiです。動作環境・導入方法を確認してください。GitHub Latestへ自動転送しません。

AIが準備中のときはどうなりますか？

通常は最初の生成・採点結果が完成してから候補を表示します。その間も読みの表示・編集・取消を続けられます。候補が出るまでの時間は環境で変わります。AIを切った場合や実行できない場合はMozcで入力を継続します。

94.0%は実アプリでの精度ですか？

固定変換器のオフライン開発評価です。Standard、AI準備後、指定前文あり、RTX 3060、AJIMEE-Bench 200問の条件です。導入済みIMEの実アプリ精度や他IMEの最新比較ではありません。評価と確認範囲をご覧ください。

Windowsの警告が出るのはなぜですか？

配布MSIは未署名です。SmartScreenは評判も確認するため、警告が表示される場合があります。配布元確認とSmartScreenの説明を確認してください。

無料ですか？

無料のオープンソースソフトウェアです。コードはApache-2.0 / MIT、Mozcへの変更はBSD-3-Clause。同梱モデル等は別のライセンスが適用されます。支援の有無による機能制限はありません。

ユーザー辞書や学習は使えますか？

Mozcのユーザー辞書と学習を利用できます。アンインストール後もユーザーデータは残ります。保存先と削除方法はプライバシーへ。

不具合はどこへ報告できますか？

GitHub Issuesへ。診断情報は自動送信されません。個人情報を添付せず、必要な読み・結果・版・環境・手順を記載してください。セキュリティの問題はSECURITY.mdを確認してください。
