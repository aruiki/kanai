ASTERIA JAPANESE INPUT

IMEの比較と開発状況

Microsoft IME・Google日本語入力と同条件で比較。AJIMEE 198問でKotori 88.4%、Microsoft 59.6%、Google 58.1%。実際の問題文、測定条件、CSVとv1.1.3の公開状況を掲載。

AJIMEE-Benchでは、どんな文を変換する？

単語を知っているだけでなく、文の意味に合う漢字を選ぶ必要があります。実際の評価データから3問を抜粋しました。

全IMEで、前の文を渡さず、Spaceを1回押した第1候補をEnterで確定して採点。数字・記号はNFKCで揃え、AJIMEE 200問のうち入力できない2問を除いた198問を比較しています。学習は既定設定のまま、問ごとにテキストとフォーカスをリセットしています。

この測定はbeta.8の記録です。現在のv1.1.3 / v1.1を再測定した数値ではありません。同音語・人名・打ち間違いはプロジェクト独自の各40問です。打ち間違い補正ではMicrosoft IMEと同率、Google日本語入力を下回りました。

現在の公開版 v1.1.3

2026年10月12日公開。日本語を含む保存先、文末の文法語、Mozcの入力補正をAIが取り消す問題を修正しました。Asteria64.msiは未署名、内部版は3.34.6431.100です。

Windows CIで、公開MSIの導入・「日本語」「東京」のTSF実入力・削除を確認しています。削除時は再起動要求（終了コード3010）がありました。これは短い2例の導入確認で、複数アプリや長時間利用の受入れを代替しません。

StandardはAJIMEE 183/200（91.5%）、最終評価用は289/300（96.3%）を維持。版・ハッシュ・測定条件・検証範囲 →

確認が続いていること

  • コード署名はv1.1.3では未実施です。
  • 長時間試験、ノートPC・設定画面・更新導入などの受け入れ確認に残項目があります。
  • 修正対象のAI ON/OFF効果を、複数のWindowsアプリで実入力する受入れ確認は未実施です。
  • CPUで長い文を打ってすぐSpaceを押すと、AIが間に合わずMozcの結果になる場合があります。
  • 評価用セットの数値を、すべてのアプリ・PC・文章へ一般化することはできません。
