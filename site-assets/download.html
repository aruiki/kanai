ASTERIA JAPANESE INPUT

ダウンロードと導入方法

Asteria64.msiで導入するWindows日本語IME。公開版v1.1.3、必要な環境、SHA-256、更新と削除の方法。GPUなしでも利用できます。

配布している版

公開版 v1.1.3

通常の導入向け。GitHub ReleasesのLatestへ進み、Asteria64.msiをダウンロードします。

日本語を含む保存先、文末表現、Mozcの入力補正をAIが取り消す問題を修正しました。

ファイルは現行のAsteria-Japanese-IMEリポジトリで配布しています。未署名です。

使い方と困ったとき

必要な環境

項目必要な環境おすすめ
OSWindows 10 1809以降 / Windows 11（x64）Windows 11
メモリ8 GB16 GB
ディスク1.7 GBの空き容量
GPUなしでも動作。内蔵GPUはAIに使いません。専用GPU・Vulkan対応・VRAM 3 GB以上

AIモデルとGPU実行環境は同梱しています。GPUのドライバー以外にCUDAなどの準備は不要です。ARM版Windowsには対応していません。動作確認済みのGPUとしてRTX 3060が記録されています。

MSIを実行して、入力方式を切り替える。

  1. GitHub Releasesでリリースノートを確認し、Asteria64.msiをダウンロードします。
  2. MSIをダブルクリックし、管理者の確認（UAC）を承認します。
  3. Win + SpaceでAsteria日本語入力へ切り替えます。半角/全角で日本語入力をON/OFFできます。
  4. デスクトップまたはスタートメニューの「Asteria日本語入力の設定」を開き、「AI変換」タブで品質とAIの状態を確認できます。

v1.1.3は未署名のため、Windowsの警告が表示される場合があります。ファイルの照合方法と対処は利用ガイドへ。

Get-FileHash .\Asteria64.msi -Algorithm SHA256

更新・アンインストール

v0.3.0-beta.6以降は、新しいMSIを上書きして更新できます。設定・学習・ユーザー辞書は引き継ぎます。それより古い版は一度アンインストールしてから導入してください。入力中のアプリがあると、再起動を求められる場合があります。

削除はWindowsの「設定 → アプリ」からAsteria日本語入力を選びます。ユーザーデータは再導入時に引き継ぐため残ります。削除後のデータの扱いはプライバシーと削除で説明しています。

自動更新の通知はありません。Releasesで更新を確認できます。
