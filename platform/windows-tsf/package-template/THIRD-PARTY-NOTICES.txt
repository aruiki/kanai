KanaAI Windows beta third-party notices
========================================

This package is an unsigned portable Workbench/CLI beta.  KanaAI-authored
launchers and configuration are distributed under the KanaAI project license;
the components below retain their own terms.  This file is an inventory and
notice index, not a substitute for review of the license text for a particular
build.

Mozc
----

The package may contain the locally built `kanai-mozc-bridge.exe`.  It is built
from the pinned Mozc checkout and the KanaAI bridge patch.  Google-authored
Mozc code is not relicensed by KanaAI.  The package preserves the following
unmodified upstream material under `legal/`:

* `Mozc-LICENSE.txt` — the Mozc license and dictionary terms.
* `Mozc-AUTHORS.txt` — the upstream authors list.
* `Mozc-CONTRIBUTORS.txt` — the upstream contributors list.
* `Mozc-README.md` — the upstream component description and license map.
* `Mozc-VOCABULARY-POLICY.md` — the upstream vocabulary/conversion policy.
* `Mozc-dictionary-README.txt` — the OSS dictionary and data terms.
* `Mozc-dictionary-manual-README.md` — the manual dictionary README when it is
  present in the pinned checkout.

The OSS dictionary is mixed/component-specific (including IPAdic, ICOT, and
Okinawa dictionary terms).  Those terms are not replaced by the KanaAI license.
No model weights, fonts, or user dictionaries are bundled by this package.

Other packaged inputs
---------------------

The `legal/` directory also contains the KanaAI license files, the lockfiles
used to resolve Rust and web dependencies, and the exact Mozc bridge patch.
When the locked build inputs are available, the packager copies license and
notice files from the installed npm and Cargo dependency trees into
`npm-licenses/` and `rust-licenses/`, and records their hashes in
`THIRD-PARTY-INVENTORY.json`.  Dependency license metadata and any transitive
notices must still be reviewed for the exact dependency set selected by the
release build.  The package does not claim that a checksum, a portable ZIP, or
this inventory is a publisher signature.

TSF boundary
------------

No TSF TIP DLL is built, included, registered, or shipped in this phase-1
package.  The optional native executable is a console/workbench seam only.
